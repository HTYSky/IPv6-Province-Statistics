# IPv6 省级统计助手使用说明

## 系统要求
- Windows 10 / 11，64 位
- 无需安装 .NET Runtime 或 Microsoft Office
- 无需联网

## 使用方法
1. 解压绿色包到任意目录
2. 双击运行 `IPv6省级统计助手.exe`
3. 把当月四个 Excel 文件（1、4、5、8 表）一起拖入窗口，或点击「选择四个文件」
4. 核对自动识别的统计年月，如需修正可在年月输入框中调整
5. 选择输出目录（软件会在下面创建「YYYY年MM月统计结果」文件夹）
6. 点击「生成 31 个统计表」
7. 生成完成后可使用「打开输出文件夹」查看结果

## 结果文件命名
每个省级行政区生成一个文件，命名格式：`省份名-YYYY年MM月.xlsx`

## 错误处理
如果数据存在问题（缺少省份、数值为空、月份冲突等），软件会在右侧列出精确到文件、sheet、行号、单元格的说明，不会生成任何正式结果。

## 注意事项
- 软件完全离线运行，所有数据仅在本机处理
- 当前版本未进行代码签名，首次运行时 Windows 可能提示安全警告，选择「更多信息」→「仍要运行」即可
